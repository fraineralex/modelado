# Normas del repositorio

- Mantener TypeScript estricto y resultados matemáticos calculados, nunca hardcodeados.
- Ejecutar `npm run lint`, `npm run test` y `npm run build` antes de finalizar.
- Mantener cero overflow en viewports de presentación y separar matemática de visualización.
- Documentar cualquier asset externo; no cargar recursos remotos en runtime.
- Aclarar las representaciones pedagógicas que no pertenezcan al modelo original.
- No leer archivos `.env` ni `.env.local`.
- No usar el prefijo `codex/` en ramas, commits ni PRs.
