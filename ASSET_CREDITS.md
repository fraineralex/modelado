# Créditos de recursos

La escena del centro de datos utiliza exclusivamente geometrías procedurales creadas en Three.js: racks, gateway, balanceador, servidores, base de datos, piso técnico y partículas. No se descargaron modelos externos ni se cargan recursos remotos en ejecución.

Las tipografías IBM Plex y KaTeX se empaquetan localmente mediante sus paquetes npm.
